Set a course password

Pick the course, type the password you will give students and (optionally) the Google Drive link of that course’s reading folder. Copy the result into config.js under courses → dmp or courses → igd. Neither the password nor the folder link is stored in readable form.

Then

  1. Open config.js in a text editor and find the course under courses:.
  2. Replace its passwordHash (and, if you entered a link, its readingFolder) with the values above.
  3. Save. Students signed in with the old password keep their session until it expires; to force everyone to sign in again immediately, also lower sessionHours temporarily.

The folder link is encrypted with AES-GCM using a key derived from the password (PBKDF2, 200 000 rounds), the same scheme the sign-in uses to unlock it. This page needs to be opened from the file or over https for the encryption to work.
